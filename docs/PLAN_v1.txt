CHOIX ACTUEL

🟩 Code → GitHub
🟩 Documentation → GitHub
🟨 Modèle → test GitHub

STRATÉGIE

1. Nettoyer le premier commit
2. Corriger le .gitignore
3. Vérifier les tailles des fichiers
4. Ajouter le modèle
5. Ajouter les Parquet
6. Créer un commit propre
7. Effectuer le push
8. Mesurer le temps de transfert
9. Vérifier le dépôt GitHub
10. Tester un clone du dépôt
11. Vérifier que les artefacts sont récupérables

DÉCISION APRÈS TEST

🟩 GitHub fonctionne correctement
→ conserver les artefacts dans GitHub.

🟨 GitHub fonctionne mais les transferts sont trop longs
→ étudier un stockage externe.

🟥 GitHub bloque certains fichiers
→ déplacer uniquement les fichiers concernés vers un stockage externe.

CRITÈRE DE SORTIE

🟩 Code disponible sur GitHub
🟩 Documentation disponible sur GitHub
🟩 Modèle accessible
🟩 Données dashboard accessibles
🟩 Clone fonctionnel
🟩 Temps de récupération acceptable
